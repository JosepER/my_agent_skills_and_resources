## 1. Choosing a palette

The chart palette has 8 main tones plus Neutral. Neutral is the default. The other palettes are used only when the content is a **flagship report** whose page uses the matching website (AEM) theme. For example, a page on the Forest or Grass theme gets the Green palette.

| Chart palette | Website themes it pairs with |
|---|---|
| Neutral (default) | Midnight, Light |
| Green | Forest, Grass |
| Turquoise | Grass, Turquoise |
| Blue | Ocean, Sky |
| Purple | Berry, Lilac |
| Aubergine | Plum, Berry |
| Orange | Orange, Burgundy |
| Yellow | Yellow, Burgundy |
| Red | Orange, Burgundy |

The tones were picked from the 11 web UI theme colours. Each tone has a 7-step sequential gradient. The 8 tones are extended into the 14-colour ordered palette. Two bright blues act as highlight and baseline.

## 3. Sequential ramps (dark -> light, 7 steps)

Use for quantitative scales that run low to high (income, temperature, age): choropleths, heatmaps, binned values. Map light = low and dark = high unless the data suggests otherwise. Sequential reads more intuitively than diverging, so prefer it when there is no meaningful midpoint.

## 4. Diverging pairs

Use a diverging scale when there is a meaningful midpoint, to stress the extremes, or to show differences: negative vs positive values, election results, Likert scales. It has a bright middle and darker ends in two different hues. Build it by joining two sequential ramps at their light ends:

`A1 A2 ... A7 | B7 ... B2 B1` (light steps meet in the middle, dark steps at the ends)

| Palette (A) | Pairs with (B) |
|---|---|
| Neutral | Cyan highlight ramp: 3093B2 23A9C6 2FBAD9 64CBE1 6CC4D7 3FD2F2 45DEFF |
| Green | Purple |
| Turquoise | Yellow |
| Blue | Yellow |
| Purple | Green |
| Aubergine | Green |
| Orange | Turquoise |
| Yellow | Green |
| Red | Turquoise |

For the Neutral diverging scale, the spec lists the Cyan ramp from 3093B2 to bright 45DEFF. Put its bright end at the midpoint, mirroring the Neutral light end.

## 5. Ordered palette: 14 colours in order of appearance

Use for categorical data with more series than a 7-step row allows, or for unrelated categories that need distinct hues (e.g. investment types in a stacked column chart). Assign in this order:

1. `#464E70` grey (Neutral tint)
2. `#46AEA7` turquoise
3. `#ED672D` orange (Burgundy accent)
4. `#3A8415` green (Grass accent)
5. `#C63963` aubergine (Lilac accent)
6. `#F2AE00` yellow (highlight)
7. `#1162D4` blue (Sky accent)
8. `#9D2EBD` purple (highlight)
9. `#BA1212` red (highlight)
10. `#97D926` green tint
11. `#7A473E` brown
12. `#FF667A` pink
13. `#0A4095` dark blue
14. `#BF7B15` yellow tint

The order is set for accessibility, so keep it. To highlight one column or bar in a chart using this palette, put a light grey `#E8EDF2` band behind it. Do not recolour the column.

## 6. Highlight and baseline

The two core highlight blues work with all 8 palettes. They suit line, column, bar and area charts.

| Role | Fill | Line | Label |
|---|---|---|---|
| Default line | Neutral 2 (`#232A52`) | 2px | Noto Sans Medium `#353C61` |
| Baseline: Ocean accent (e.g. OECD average) | `#48A7FF` | 3px | in `#48A7FF` |
| Highlight: Cyan (e.g. Euro Area) | `#45DEFF` | 3px | in `#45DEFF` |
| Highlighted stacked-bar row | Pale blue `#E6F2FF` band | none | Noto Sans Extrabold `#586179` |
| Period / projection band, highlighted column | Light grey 2 `#E8EDF2` | none | - |

- Ocean tints for stacked baseline segments: 48A7FF 56B7FF 6BC6FF 85D3FD A1E0FC BDEDFD DBF8FF.
- Cyan shades: 45DEFF 3FD2F2 6CC4D7 67CDE3 2FBAD9 23A9C6 3093B2.
- Each theme's accent colour may also highlight data in thematic charts.
- Highlight one main value, or at most three. Too many bright colours stop drawing the eye.
- Area charts: overlapping areas use 50% transparency.
- Never highlight text with a background colour. Emphasis on a label is weight (Extrabold) or matching a line's colour.
